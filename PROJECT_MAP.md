## 📌 1. ОБЩИЙ ОБЗОР И ТЕХНОЛОГИЧЕСКИЙ СТЕК

**«Мафия Онлайн: Город Засыпает»** — кроссплатформенная многопользовательская веб-игра в классическую и городскую мафию с глубокой мета-системой (уровни, опыт, кланы, кастомизация, магазин, ломбард, дейли-бонусы, система квестов и ивентов, встроенная модерация и панель администратора).

### Архитектурный стек:
* **Фронтенд:**
  * **React 19** + **TypeScript** + **Vite 8**
  * **Tailwind CSS v4** (с noir/mafia цветовой палитрой и анимациями)
  * **Lucide React** (иконки интерфейса)
  * **Recharts** (графики детальной статистики побед и ролей)
  * **Motion** (плавные анимации переходов фаз и карточек)
  * **Canvas Confetti** (эффекты побед и получения наград)
  * **Web Audio API** (звуковой движок с noir-эффектами: выстрелы, колокол, таймер, ночь)
* **Бэкенд:**
  * **Node.js** + **TypeScript** (`tsx server.ts`)
  * **Express 4.21** (REST API)
  * **WebSockets (`ws`)** — двусторонний real-time протокол для матчей, чатов и онлайн-статусов
  * **SQLite3** (`database.sqlite`) — локальная реляционная база данных с автоматическим созданием таблиц, индексами и плавной миграцией из legacy JSON
  * **Bcryptjs** — криптографическое хеширование паролей
  * **Dotenv** — конфигурация окружения с fallback-значениями в коде
* **Единый процесс:**
  * Сервер слушает порт `3000`. В режиме разработки (`npm run dev`) Express монтирует `vite.middlewares` для единого адреса фронтенда и бэкенда.

## 🏛️ 3. АРХИТЕКТУРА СЕРВЕРА (`/server.ts` и `/server/`)

### 3.1. Главный модуль `server.ts`
1. **Инициализация окружения и БД:**
   * С первой строки импортирует `'dotenv/config'`, гарантируя доступ к `process.env`.
   * Вызывает `initDatabase()`, проверяет наличие SQLite-таблиц и мигрирует данные.
2. **WebSocket-шлюз (`/ws`):**
   * Обрабатывает подключение игроков.
   * Отслеживает онлайн-статус по `userId` (`userSockets = Map<string, Set<WebSocket>>`).
   * Позволяет мгновенно слать push-уведомления конкретному игроку (`notifyUser`), например приглашения от друзей.
3. **Middleware безопасности:**
   * `requireAuth` — проверяет Bearer-токен сессии.
   * `requireAdmin` — гарантирует доступ только администраторам (проверяет флаг `isAdmin`, роль `admin` или совпадение с email администратора).
4. **Маршрутизация HTTP API:**
   * Делегирует операции специализированным модулям баз данных (`userDb`, `shopDb`, `clanDb`, `dailyBonusDb`, `eventsDb`, `reportsDb`) и игровому менеджеру `roomManager`.

### 3.3. Игровой автомат и механики (`server/game/`)

#### 1. `roomManager.ts`
* Создает уникальные 6-значные коды комнат (например, `MF-7492`).
* Поддерживает публичные и приватные (с паролем) комнаты.
* Управляет жизненным циклом игроков в комнате (подключение, отключение, статус готовности, передача прав хоста).
* Управляет настройками: длительность ночи, длительность дня, скрытые роли, состав колоды.

#### 2. `engine.ts`
* Реализует конечный автомат игровых фаз:
  ```text
  [LOBBY] ➔ [ROLE_REVEAL] ➔ [NIGHT] ➔ [MORNING_REPORT] ➔ [DAY_DISCUSSION] ➔ [VOTING] ➔ [EXECUTION]
       ▲                                                                                     │
       └────────────────────────── [GAME_OVER] ◄─────────────────────────────────────────────┘
  ```
* **Приоритет ночных действий:**
  1. **Любовница / Путана** — блокирует цель (цель не может совершить ночное действие).
  2. **Шериф** — проверяет статус игрока (узнаёт, мафия ли он).
  3. **Доктор** — накладывает защиту (спасает от ночного покушения).
  4. **Мафия / Дон** — совместный выбор жертвы и ночной выстрел.
  5. **Маньяк** — одиночный выстрел в выбранную жертву.
* **Условия победы:**
  * **Победа Города:** Все члены Мафии и Маньяк устранены.
  * **Победа Мафии:** Количество живых мафиози равно или превышает количество живых мирных граждан, а Маньяк мертв.
  * **Победа Маньяка:** Маньяк остался 1 на 1 с любым последним игроком или один в городе.

#### 3. `experience.ts`
* Расчёт опыта по формуле: `BaseXP + WinBonus + SurvivalBonus + RoleMasteryMultiplier`.
* Повышение уровня профиля и автоматическая выдача кредитов за новые уровни.

### 5.1. Управление состоянием (`App.tsx`)

### 5.2. Роли и команды в игре (`src/data/roles.ts`)

| Роль | Команда | Ночное действие | Описание |
| :--- | :--- | :--- | :--- |
| **Мирный житель** | Город | Нет | Днем участвует в обсуждении и поиске мафии, голосует. |
| **Шериф** | Город | Проверка | Ночью выбирает игрока и узнает, принадлежит ли он к Мафии. |
| **Доктор** | Город | Лечение | Ночью спасает выбранного игрока от гибели. Не может лечить себя 2 ночи подряд. |
| **Любовница** | Город | Блокировка | Ночью навещает игрока, лишая его возможности использовать ночную способность. |
| **Мафия** | Мафия | Выстрел | Сообща с другими мафиози выбирает жертву для устранения. |
| **Дон Мафии** | Мафия | Поиск Шерифа | Лидер мафии. Ночью ищет Шерифа среди горожан. |
| **Маньяк** | Одиночка | Выстрел | Одиночный убийца. Стреляет каждую ночь по собственному усмотрению. Побеждает один. |

## 📡 6. СПРАВОЧНИК СЕТЕВЫХ ПРОТОКОЛОВ

### 6.1. REST API Эндпоинты

#### Аутентификация и пользователи (`/api/auth/*`):
* `POST /api/auth/register` — регистрация нового аккаунта (логин, пароль, email).
* `POST /api/auth/login` — вход по email и паролю.
* `POST /api/auth/sync-google` — синхронизация или создание аккаунта через Google Firebase.
* `GET  /api/auth/me` — получение профиля текущего пользователя по Bearer-токену.
* `POST /api/auth/logout` — завершение сессии.
* `GET  /api/auth/search-users` — поиск игроков для добавления в друзья.
* `POST /api/auth/update-nickname` — смена никнейма (бесплатно или за сертификат/монеты).
* `POST /api/auth/update-avatar` — обновление аватарки или сида генерации.
* `GET  /api/auth/friends` — получение списка друзей с их текущим онлайн-статусом.
* `POST /api/auth/friends/add` — отправка запроса в друзья.
* `POST /api/auth/friends/remove` — удаление из друзей.

#### Игровые комнаты (`/api/rooms/*`):
* `GET  /api/rooms` — получение списка всех доступных комнат.
* `POST /api/rooms/create` — создание новой игровой комнаты с параметрами.

#### Кланы (`/api/clans/*`):

### 6.2. WebSocket Протокол (`/ws`)

#### Сообщения от Клиента к Серверу (`Client -> Server`):
* `join_room` — подключение к комнате по `roomCode` и `playerId`.
* `leave_room` — добровольный выход из комнаты.
* `player_ready` — переключение статуса готовности в лобби.
* `update_settings` — обновление параметров комнаты (только хост).
* `start_game` — запуск матча (только хост при достаточном количестве игроков).
* `chat_message` — отправка сообщения в чат (с указанием канала: общий, мафия, мертвые).
* `night_action` — выбор цели ночного действия (выстрел, проверка, лечение, блок).
* `vote` — голосование днем за исключение подозрительного игрока.
* `kick_player` — исключение игрока из лобби (только хост).

#### Сообщения от Сервера к Клиенту (`Server -> Client`):
* `room_state` — полное синхронизированное состояние комнаты (`ClientRoomState`).
* `chat_message` — входящее сообщение чата с проверкой видимости для роли.
* `error` — сообщение об ошибке (например, «Комната заполнена» или «Неверный пароль»).
* `room_invite` — персональное всплывающее приглашение в игру от друга.
* `xp_reward` — мгновенное уведомление о полученном опыте и повышении уровня.

## 🏆 8. КЛЮЧЕВЫЕ ДОСТОИНСТВА АРХИТЕКТУРЫ

1. **Zero-Configuration локальный старт:** Благодаря автономной SQLite-базе и fallback-значениям для супер-администратора проект запускается «в один клик» (`npm run dev`) без необходимости настраивать сторонние базы данных или `.env`.
2. **Бесшовная синхронизация состояний:** Сочетание строгого конечного автомата на сервере (`engine.ts`) и клиентского состояния исключает рассинхронизацию между игроками.
3. **Разделение ответственности:** Четкая модульность клиентских экранов (`components/`), серверных обработчиков данных (`server/db/`) и игрового ядра (`server/game/`).
4. **Безопасность:** Пароли хешируются с солью через `bcrypt`, ночные действия мафии скрыты на уровне сервера и не передаются мирным жителям до оглашения утренних итогов.
